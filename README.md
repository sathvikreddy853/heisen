# Heisen: <small> Programming Beyond Classical Limits </small> 
A yet to be quantum programming language.


## Building and Running

### Prerequisites
- Clang++ with C++23 support
- Make

### Build
To build the project, run:
```bash
make
```

### Run
To run the compiler:
```bash
./heisen <input-file>
```

### Clean
To clean the build artifacts:
```bash
make clean
```
